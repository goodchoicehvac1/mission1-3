## 💡 핵심 평가 요약
- **반영 (2건)**: 엔터(Enter) 키로 영화 추가 기능, 빈칸 입력 시 안내창(`alert`)
- **보류 (3건)**: 외부 API 포스터 연동, 파이어베이스 로그인 구축 (기획서 목적 위배 및 과잉 기능), 다크모드 강제 (취향 문제)
- **되묻기 (1건)**: "요즘 스타일로 화려하게" (구체적 요구사항 파악 필요)
- **자체 발견 (1건)**: [초기화] 클릭 시 확인창(`confirm`) 부재로 인한 데이터 유실 위험
